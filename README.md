# Eggchat

Легкий та простий чат-додаток.

## Опис

**Eggchat** — це мінімалістичний чат, створений для швидкого та зручного обміну повідомленнями.

## Можливості

- Обмін повідомленнями в реальному часі
- Проста установка та запуск
- Кросплатформена підтримка

## Встановлення

```bash
git clone https://github.com/flopiy/Eggchat.git
cd Eggchat
```
